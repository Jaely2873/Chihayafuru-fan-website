# Chihayafuru-fan-website
A fan website for the Japanese manga and anime series Chihayafuru

What is it?

The World of Chihayafuru is a fan website I made for the Japanese manga and anime series Chihayafuru. It features information about what the series is about, characters within the series, the sport on which the series is based around, and a quiz for the user to take after they finish reading through the website.

Why did I make it?

I'm a beginner to programming so I wanted to start out both with something simple and something that would keep my interest. Chihayafuru is one of my favorite series, yet it is very underated. I wanted to make a website that illustrated my passion for the series while also helping build my programming skills up.

How to use:

You can navigate between pages using the links in the navBar. It's recommended to do the quiz last if you're not familiar with the series. To install copy and paste the link into a browser and it should open to index.html.
